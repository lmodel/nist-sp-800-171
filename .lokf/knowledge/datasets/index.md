# Datasets

* [nist-sp-800-171 LinkML schema](nist-sp-800-171-linkml-schema.md) - The LinkML schema of NIST SP 800-171 Revision 3, `src/nist_sp_800_171/schema/nist_sp_800_171.yaml` (schema id `https://w3id.org/lmodel/nist-sp-800-171`, version 3.0.0): eight classes, three enums and seven identifier types. Its `lokf adapt` copy `.lokf/nist-sp-800-171.yaml`, rooted on the family, the security requirement and the organization-defined parameter, is the bundle's domain schema.
* [NIST's SP 800-171 catalog copy](sp-800-171-catalog-copy.md) - NIST's catalog of SP 800-171 Revision 3 in the Open Security Controls Assessment Language (OSCAL), which carries the assessment procedures of SP 800-171A Revision 3 too, copied with NIST's licence from usnistgov/oscal-content v1.6.0 into `src/nist_sp_800_171/schema/oscal-content/` and matched to that release by git object hash. The tests derive the whole publication from it.
* [Generated artefacts](generated-artefacts.md) - What the LinkML generators and `lokf adapt` write from the schema: `project/` (JSON Schema, OWL, SHACL, ShEx, JSON-LD, GraphQL, protobuf, SQL, TypeScript, Excel and Java), the Python dataclasses and Pydantic models in `src/nist_sp_800_171/datamodel/`, `docs/schema/` and `docs/elements/`, and `.lokf/nist-sp-800-171.yaml`. None is edited by hand.
* [Test data and tests](test-data.md) - The schema's tests: nine valid examples and 34 counter-examples under `tests/data/`, `tests/test_data.py`, which holds each to the validator, `tests/test_upstream.py`, which derives the publication from NIST's catalog, and `tests/test_schema_rules.py`, which holds the adapt copy apart from LOKF and the slsa, github-actions, oscal, spdx and nist-sp-800-218 copies in `tests/neighbours/`.
