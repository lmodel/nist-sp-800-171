# Security Assessment and Monitoring (03.12)

NIST's catalog renders the family as the group `SP_800_171_03.12`, titled Security Assessment and Monitoring, with 5 numbered requirements.[^nist_sp800-171_rev3_catalog.json] Its 4 requirements in force carry 3 organization-defined parameters and 17 assessment objectives:

- `03.12.01` Security Assessment
- `03.12.02` Plan of Action and Milestones
- `03.12.03` Continuous Monitoring
- `03.12.05` Information Exchange

Revision 3 withdrew one of the family's requirements:

- `03.12.04`, incorporated into `03.15.02`
